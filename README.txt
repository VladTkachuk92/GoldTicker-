GoldTicker Android
==================

Fullscreen landscape XAUUSD price display.

- Source: TradingView scanner / OANDA:XAUUSD
- Only the price, huge white digits on black
- No chart, no percentage, no browser chrome
- Screen stays awake
- Refresh target: ~0.75 s

GitHub Actions will build the APK automatically.
Artifact: GoldTicker-APK -> app-debug.apk
